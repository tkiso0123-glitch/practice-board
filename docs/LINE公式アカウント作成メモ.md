# LINE公式アカウント作成メモ

作成：2026-11-12。LINE側の画面の項目名は変わることがあります。

## 方針
- 講座の公式なものと誤解されないよう、**スクール名や講座のロゴは使わない**
- クラスの中だけで使うので、**検索で見つからない設定**にする
- 認証済みアカウントの申請はしない（不要）。プランは無料（コミュニケーションプラン）

## 作成時の入力
| 項目 | 入れる内容 | メモ |
|---|---|---|
| ログイン方法 | 自分のLINEアカウントでログイン | LINEビジネスIDが同時にできる |
| アカウント名 | **練習ボード** | グループ内でBotの名前として表示される。あとから変更できる |
| メールアドレス | 木曽さんのGmail | |
| 会社・事業者の所在国・地域 | 日本 | |
| 会社・事業者名 | 木曽 稔之（個人名） | 一般の人には表示されない想定。KoTo Soundなど事業の名前とは分ける |
| 業種 | 大業種「個人」→ 小業種「個人（その他）」 | 近いものでよい |
| 運用目的 | 「その他」または「情報発信」 | 集計用の質問。動作には影響しない |
| 主な使い方 | メッセージ配信用 | |

## 作成後の設定（LINE Official Account Manager）
| 場所 | 設定 |
|---|---|
| 設定 → アカウント設定 → 機能の利用 | 「グループ・複数人トークへの参加を許可する」→ **オン** |
| 設定 → アカウント設定 → 検索結果での表示 | **オフ**（クラス外の人に見つからないように） |
| 設定 → 応答設定 | チャット **オフ**／Webhook **オン**／応答メッセージ **オフ**／あいさつメッセージ **オン** |
| 設定 → Messaging API | 「Messaging APIを利用する」→ プロバイダーを新規作成（下記） |
| プロフィール → ステータスメッセージ | 「仲間と練習・勉強会をしよう」（20文字以内） |
| プロフィール画像 | 後日ChatGPTで作成（作るまでは初期画像のまま） |

### プロバイダー名：**練習ボード（木曽）**
LINEでログインするときの同意画面に表示されるので、仲間が見て誰のものかわかる名前にする。
あとで作る「LINEログイン」チャネルも、必ず**同じプロバイダー**に作る（違うとuserIdが一致せず、個別通知が届かない）。

### あいさつメッセージ（友だち追加されたときに自動で送られる・通数はかからない）
```
友だち追加ありがとうございます😊
練習・勉強会ボードのお知らせ用アカウントです。

参加した会が成立したときや、中止になったときに、ここに個別でお知らせが届きます。
このトークにメッセージを送っていただいても、お返事はできません（内容は保存しません）。
```
※ボードのURLは、公開後にここへ追記する。

## 控えておくもの（あとでセットアップに使う）
- ベーシックID（`@` で始まる英数字）：Official Account Manager のホームに表示される
- Messaging APIの「チャネルシークレット」と「チャネルアクセストークン（長期）」：LINE Developers で確認する。**秘密情報なので、チャットやファイルには貼らない**
