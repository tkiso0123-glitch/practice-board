# 練習・勉強会ボード　セットアップ手順

キャリコン講座の仲間（LINEグループ約20人）で、面談練習・もくもく勉強会・相談会・雑談会などを
「この日のこの時間にやりたい！」と募集し、人数がそろったらLINEに知らせる仕組みです。

- **Googleのサーバー上で動くので、PCを閉じていても動き続けます。**
- 費用：Google側は無料。LINE公式アカウントも無料プラン（月200通）で始められます。
- 参加者はアカウント登録不要。URLを開いて、名前を入れて「参加する」を押すだけです。

---

## 全体の仕組み

| やること | どう届くか | LINEの通数 |
|---|---|---|
| 募集・参加の告知 | ページの「LINEで知らせる」ボタン → 本人のLINEが文面入りで開き、グループに送る | **0通**（本人が送るため） |
| 成立のお知らせ | Botが自動送信。無料枠に余裕があればグループへ、少なくなったら個別登録した参加者だけへ | グループ：20通／参加者だけ：2〜3通 |
| 取消で人数割れ・中止 | 個別登録した参加者だけへ（いなければグループ） | 2〜3通（または20通） |
| グループで「一覧」と送る | Botが予定一覧を返信 | **0通**（返信は無料） |
| Botに「登録 ニックネーム」と送る | 個別通知の受け取り登録。Botが返信 | **0通** |

**20人グループで無料（200通）の場合の目安**
- 成立通知をすべてグループに送る：月10回まで
- 個別登録した人だけに送る：月60回以上
- 「auto」（初期設定）は、月の前半はグループに送り、無料枠が残り少なくなったら自動で個別送信に切り替えます。上限を超えて送ろうとして失敗することはありません。

> 足りないときは、ライトプラン（月5,000円・5,000通、税別）に上げれば、毎回グループに送れます。
> 料金や通数の数え方は変わることがあるので、契約時にLINE公式の料金ページで確認してください。

## 用意するもの

- Googleアカウント（木曽さん個人のGmailでOK）
- LINE公式アカウント（無料で作れます）

所要時間：30〜45分ほど

---

## 手順1　スプレッドシートとスクリプトを用意する

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`練習・勉強会ボード`）
2. メニュー **拡張機能 → Apps Script** を開く
3. 左上のプロジェクト名を `練習・勉強会ボード` に変える
4. 最初からある `コード.gs` の中身をすべて消し、**Code.gs** の中身を貼り付けて保存
5. 左の「ファイル ＋」→ **HTML** → 名前を `index` にする（`.html` は自動で付きます）
   → 中身をすべて消し、**index.html** の中身を貼り付けて保存
6. 左の歯車（プロジェクトの設定）→ **タイムゾーン** を「(GMT+09:00) 東京」にする

## 手順2　初期設定を実行する

1. エディタ上部の関数選択で `setup` を選んで **実行**
2. 「承認が必要です」→ 自分のアカウントを選ぶ
   →「このアプリはGoogleで確認されていません」と出たら **詳細 → （プロジェクト名）に移動 → 許可**
   （自分で作ったスクリプトなので問題ありません）
3. スプレッドシートに `events` `members` `lineUsers` `settings` の4つのシートができていればOK

## 手順3　Webページとして公開する

1. 右上 **デプロイ → 新しいデプロイ**
2. 種類の歯車 → **ウェブアプリ**
3. 設定
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** → 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
5. そのURLをスマホで開いて、ページが表示されるか確認

## 手順4　LINE公式アカウントを作り、Messaging APIを有効にする

1. 「LINE公式アカウント 作成」で検索し、LINEビジネスIDでアカウントを作る
   （アカウント名の例：`キャリコン練習ボード`）
2. **LINE Official Account Manager** → 右上「設定」→ **Messaging API** → 「Messaging APIを利用する」
   - プロバイダーは新規作成でOK（例：`KoTo Sound` や個人名）
3. 同じく「設定」の中で
   - **アカウント設定 → 機能の利用 → 「グループ・複数人トークへの参加を許可する」をオン**
   - **応答設定**：「Webhook」オン、「応答メッセージ」オフ、「あいさつメッセージ」はお好みで
     （応答メッセージがオンだと、グループで発言するたびに自動返信が出てしまいます）
4. **LINE Developers**（developers.line.biz）にログイン → 作ったチャネル → **Messaging API設定** タブ
   - 一番下の **チャネルアクセストークン（長期）** を「発行」してコピー

## 手順5　トークンをスクリプトに保存する

1. Apps Script の歯車（プロジェクトの設定）→ 下の **スクリプト プロパティ** → 「プロパティを追加」
   - プロパティ：`LINE_CHANNEL_TOKEN`
   - 値：手順4でコピーしたトークン
2. 保存

> トークンは「合鍵」です。コードやシート、LINEには貼らないでください。

## 手順6　LINEとページをつなぐ（Webhook）

1. LINE Developers → Messaging API設定 → **Webhook URL** に、手順3のウェブアプリURLを貼り付けて「更新」
2. 「Webhookの利用」を **オン**
3. 「検証」ボタンはエラーが出ることがありますが（GASの仕様によるもの）、次の手順で動けば問題ありません

## 手順7　Botをグループに招待する

1. LINEアプリで、作った公式アカウントを友だち追加（QRコードは Official Account Manager の「友だちを増やす」にあります）
2. 講座のLINEグループの「招待」から、その公式アカウントを招待
3. Botが「このグループに、練習・勉強会のお知らせを送ります📮」と返事をすれば、**通知先の登録完了**
4. 念のため Apps Script で `checkSetup` を実行し、ログに「LINE_GROUP_ID：（英数字）」が出ているか確認
5. 試しに通知を送るなら `testPush` を実行（グループ人数ぶんの通数を使います）

> 最初に招待されたグループだけが通知先になります。グループを変えたいときは、スクリプト プロパティの `LINE_GROUP_ID` を削除してから、新しいグループに招待し直してください。

## 手順8　グループのみんなにお知らせする

グループへの案内文の例：

```
キャリコン仲間で練習や勉強会を気軽に募集できるページを作りました！
「この日のこの時間に面談練習したい」などを書くと、人数がそろったときにここにお知らせが届きます。

▼募集・参加はこちら（登録不要・ニックネームでOK）
（ウェブアプリのURL）

・グループで「一覧」と送ると、これからの予定が見られます
・Botを友だち追加して「登録 ニックネーム」と送っておくと、自分が参加した会のお知らせが個別にも届きます
・相談内容などの個人的なことは書かないでくださいね
```

## 使い方（参加者向け）

- **募集する**：「＋ 募集する」→ テーマ・日時・成立人数（面談練習は初期値3名）を入れて募集
  → 「LINEで知らせる」を押すと、文面入りでLINEが開くので、グループを選んで送る
- **参加する**：カードの「✋ 参加する」
- **取り消し・中止**：操作したときと同じスマホ・ブラウザから行えます
  （別の端末から操作したいときは、木曽さんがスプレッドシートで直接直せます）

## 管理者（木曽さん）向け

### 設定の切り替え：`settings` シートの value 列

| key | 初期値 | 内容 |
|---|---|---|
| FORMED_TO | auto | 成立通知の送り先。`auto`／`group`（毎回グループ）／`members`（参加者だけ）／`off` |
| NOTIFY_NEW | off | 新しい募集をBotがグループに通知する（1回20通） |
| NOTIFY_JOIN | off | 成立前の参加を、そのつどグループに通知する（1回20通） |
| REMIND | off | 成立した会の当日朝8時に、参加者へリマインドする |
| GROUP_RESERVE | 20 | auto のとき、グループ送信のあとに最低限残しておく通数 |

- REMIND を使うときは、`on` にしたうえで Apps Script の `installReminder` を一度だけ実行してください。

### よくある対応
- **間違った募集や不適切な書き込みを消す**：`events` シートの `status` を `中止` に書き換える
- **参加者を外す**：`members` シートの該当行を削除する
- **コードを直したとき**：デプロイ → **デプロイを管理** → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ
  （「新しいデプロイ」を選ぶとURLが変わってしまうので注意）
- **今月の残り通数を確認**：`checkSetup` を実行してログを見る

### 気をつけたいこと
- ページのURLを知っている人は誰でも見られて、書き込めます。グループの外には貼らないでください。
- 名前はニックネームで十分です。シートに残るのは「名前・日時・ひとこと」だけにしています。
- LINEからの受信（Webhook）は、GASの制約で署名の確認ができません。そのため、Botが受け付ける操作は「返信」「通知先の初回登録」「個別通知の登録」だけにしてあり、データを消したり書き換えたりはできないようにしています。
